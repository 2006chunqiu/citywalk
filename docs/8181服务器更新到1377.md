# 8181 服务器更新到 1377 条种子库 · 操作说明

> 适用对象：负责 218.197.118.44:8181 那台演示机器的同学
> 更新时间：2026-11-21
> 目标：只换数据文件 + 重启后端，不动代码、不动 .env、不动 nginx。

## 背景

- 当前 8181 后端读的是旧 **1282 条**种子库（photo 只有 11 条、family 34、local 48，长尾主题基本没货）。
- GitHub `main` 最新提交 `f9d30a8` 已换成 **1377 条**种子库（`data/poi.csv`），标签按 v3 映射重打（art 331 / park 550 / history 268 / food 229 / photo 113 / local 111 / river 66 / family 54）。
- 本次前端代码没有改动，**不用重新 build 前端**。

## 操作步骤

### 1. 拉最新代码

进入服务器上的 citywalk 仓库目录，执行：

```
git fetch origin
git pull origin main
```

如果那台机器上的代码不是 git 仓库（是直接拷贝的），先：

```
git clone https://github.com/2006chunqiu/citywalk.git
```

### 2. 核对数据文件

- `data/poi.csv` 应为 **1378 行**（含表头），表头 11 列：
  `poi_id,name,address,lng,lat,typecode,tag_ids,rating,stay_minutes,source,type_name`
- `data/poi_seed_1377.csv` 是原始 5 列种子库，备查用，后端不读它。

### 3. 重启后端

先结束占用后端端口的旧进程，再在 `backend` 目录里重新启动：

```
.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

> 端口按那台机器原来的后端端口启动，不要改；8181 是 nginx 之类反代的对外端口，保持不变。

### 4. 验证

服务器本机浏览器打开（或 curl）：

```
http://127.0.0.1:8181/api/health
```

确认三点：

1. `poi.total` 变成 **1377**
2. `byTag` 变成：park 550 / art 331 / history 268 / food 229 / photo 113 / local 111 / river 66 / family 54
3. `llm` 仍是 `up`、`amap` 仍是 `up`

再从页面生成一次路线（如 武汉大学 → 昙华林），确认能出三条方案。

### 5. 发群确认

发一张 health 截图 + 一张生成路线的页面截图，@hmc 确认。

## 注意事项

- **不要动服务器上的 `.env`**（里面有 DeepSeek Key 和高德 Key）。
- 不要改 nginx 配置、不要改端口。
- 如果 pull 时 `data/poi.csv` 冲突，直接以远端为准：
  `git checkout origin/main -- data/poi.csv`
- 如果重启后 `poi.total` 不是 1377，说明后端读的不是新文件，检查启动目录是不是 `backend`、文件路径对不对。
